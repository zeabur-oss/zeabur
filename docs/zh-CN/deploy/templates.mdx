在项目中选择**新建** → **应用模板**，选择应用，填写域名和必要字段，点击**检查变更**后应用。模板来自当前 Zeabur 版本内置的 [Zeabur Catalog](https://github.com/zeabur-oss/catalog)，部署时不会从外部下载模板。

## 开始前

- 已有项目，并有创建服务的权限。模板中的对象使用你自己的权限创建，检查变更时会列出权限不足、无法创建的对象。
- 已安装模板需要的组件，例如使用 PostgreSQL 的模板需要 CloudNativePG。模板列表会在模板下方显示**需要先安装…**。
- 如果模板需要公开域名，准备一个指向集群 Ingress 的域名。如果模板需要 HTTPS，Zeabur 必须先指定证书签发者。

## 部署模板

<Steps>
<Step>

### 选择应用

打开**新建** → **应用模板**。每个模板都会说明用途，以及需要多少 CPU 和内存。如果集群剩余的内存或 CPU 不足，模板下方会显示提醒。在上方输入名称即可筛选。

![应用模板列表，筛选 n8n 后列出三个模板，每个模板都说明用途及所需的 CPU 和内存](../images/shots/template-list.avif)

</Step>
<Step>

### 安装缺少的组件

如果尚未安装模板需要的组件，表单上方会写出缺少的所有组件和**安装方式**按钮。点击后会一次列出这些组件的安装命令，按照[查看与安装集群组件](../cluster/components.mdx)的步骤安装，再回来部署。缺少组件时，**检查变更**无法继续。

</Step>
<Step>

### 填写域名和字段

- **公开域名**：默认由模板名称和项目名称组成，可以改成自己的域名。
- **部署前须知**：模板作者列出的已知风险和处理方式，默认折叠，展开后才能查看内容，目前只有英文。部署前先阅读，例如首次启动前谁能创建管理员账号。
- 其他字段：名称和说明会随界面语言显示。标有**选填**的字段可以留空。

密码和密钥会在你的浏览器中生成，并存入模板指定的机密变量，例如 Miniflux 的 `miniflux-secrets`。部署后，可以在使用这些值的服务的**变量**中显示它们。

![部署 Miniflux 的表单，包含公开域名字段，下方说明密码会存入机密变量 miniflux-secrets](../images/shots/template-form.avif)

</Step>
<Step>

### 检查并应用

点击**检查变更**，确认要创建的对象后应用。**会启动的服务**会列出模板的服务、数据库和域名，下方显示峰值所需的 CPU 和内存。如果项目中已经部署过同一模板，页面会列出已存在的对象，需要先删除它们，或改为部署到其他项目。模板中的所有对象都会创建在当前项目的 Namespace 中。

![部署 Miniflux 的检查页面，列出将创建的机密变量、服务、数据库和域名，以及资源是否充足](../images/shots/template-review.avif)

</Step>
</Steps>

## 确认结果

应用变更后，模板的服务和数据库会出现在项目中。打开各服务的**概览**，等待副本就绪，再打开模板的公开域名，确认能看到应用页面。

模板中的每个对象，以及生成的密码机密变量，都带有三个标签：`app.kubernetes.io/instance` 和 `templates.zeabur.com/template` 是模板 ID，`app.kubernetes.io/version` 是应用版本。用 kubectl 列出本次部署的对象：

```sh
kubectl -n shop get deploy,statefulset,svc,ingress,pvc,secret -l app.kubernetes.io/instance=miniflux
```

如果模板使用数据库，还要确认 operator 的对象已就绪，例如 `kubectl -n shop get clusters.postgresql.cnpg.io -l app.kubernetes.io/instance=miniflux` 的 `STATUS` 是 `Cluster in healthy state`。

## 用 kubectl 完成相同操作

Zeabur 使用内置的 [Zeabur Catalog](https://github.com/zeabur-oss/catalog) 将模板转换为 YAML。转换在 Zeabur 内部完成，没有对应的集群对象，但你可以用 Catalog 的 `catalog` 命令生成相同的 YAML，再用 kubectl 应用。

先查看 Zeabur 使用的 Catalog 版本：打开**设置**中的**关于**，**Zeabur Catalog** 一行显示的就是它的提交。在 Catalog 源码中切换到该提交，进入 `nix develop` 后运行：

```sh
umask 077
go run ./tools/cmd/catalog template inputs -namespace shop miniflux > secrets.json
go run ./tools/cmd/catalog template render -namespace shop \
  -domain miniflux.example.com -cluster-issuer letsencrypt miniflux > plan.yaml
kubectl -n shop apply -f secrets.json
kubectl -n shop apply -f plan.yaml
```

- `template inputs` 生成模板所需的密码和密钥，每次运行都会生成新值，因此只运行一次，后续升级沿用同一份机密变量。不要将 `secrets.json` 纳入版本控制。
- 如果模板有需要填写的字段，将值写成 JSON 对象，例如 Dify 的 `{"storageRegion":"us-east-1", ...}`，通过 `-values inputs.json` 传入。字段名称位于模板 `template.yaml` 的 `inputs` 中。
- 必须先安装模板 `requires` 中列出的组件。

删除整个模板：

```sh
kubectl -n shop delete all,ingress,pvc,secret,configmap,networkpolicy -l app.kubernetes.io/instance=miniflux
```

数据库等 operator 的对象也带有相同标签，用 `kubectl -n shop get <种类> -l app.kubernetes.io/instance=miniflux` 找到后再删除。删除卷和数据库时，也会删除其中的数据。

## 网络规则

模板不会拦截整个项目的流量。哪些来源能连接项目中的副本，由项目的 `zeabur-project` 决定，见[安全性](../reference/security.mdx)。出站连接不受限制，应用可以连接模型服务、Webhook、邮件服务器和用于备份的 S3。

要限制某个应用的出站连接，自行添加 NetworkPolicy。下面的示例只允许 Umami 查询 DNS 和连接自己的数据库：

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: umami-egress
spec:
  podSelector:
    matchLabels:
      templates.zeabur.com/template: umami
      app.kubernetes.io/name: umami
  policyTypes: [Egress]
  egress:
  - to:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: kube-system
      podSelector:
        matchLabels:
          k8s-app: kube-dns
    ports:
    - {protocol: UDP, port: 53}
    - {protocol: TCP, port: 53}
  - to:
    - podSelector:
        matchLabels:
          cnpg.io/cluster: umami-db
    ports:
    - {protocol: TCP, port: 5432}
```

用 `kubectl apply -n <项目的命名空间> -f umami-egress.yaml` 应用。`podSelector` 只选择应用的副本，不要选中数据库：数据库需要连接 Kubernetes API 和用于备份的 S3，拦截这些连接会导致数据库停止运行，备份也会失败。

## 常见失败情况

- 名称已存在：模板使用固定的对象名称。如果同一项目中已经部署过相同模板，或存在同名的机密变量，检查变更时会列出冲突。改为在其他项目中部署。
- 字段格式不符：字段下方会说明要求的格式，按要求修改后重新检查。
- 检查变更提示集群不支持某种对象：模板需要的组件尚未安装完成，或仍在启动。到**组件**页面确认状态。
