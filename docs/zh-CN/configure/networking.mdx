服务的**网络**标签页管理三件事：**私有网络**列出集群内其他服务连接这个服务的地址，**对外端口**让集群外的客户端不经过域名直接连接，**连接规则**决定哪些服务能连进来、这个服务能连到哪里。公开域名和 HTTPS 见[添加公开域名与 HTTPS](./domains.mdx)。

![web 服务的网络标签页，列出公开域名与私有网络](../images/shots/service-networking.avif)

## 开始前

- 有权限修改项目内的服务。Helm、Argo CD 或 Flux 管理的服务不能在这里开放端口或添加规则，需要在对应工具中修改。
- 连接规则需要集群的网络插件（CNI）执行。K3s 内置的控制器支持这些规则；插件不支持时，规则仍能创建，但不会阻止任何连接。
- 开放端口需要负载均衡器。K3s 内置的 ServiceLB 和 Zeabur 安装程序安装的 RKE2 都提供负载均衡器。

## 通过私有地址连接其他服务

**私有网络**中的每一行是一个 Kubernetes Service，例如 `web:8080`。同一项目内的服务直接通过这个地址连接，例如 `http://web:8080`。

从其他项目连接时，使用**从其他项目连接**后面的完整地址，例如 `web.demo.svc.cluster.local:8080`。项目已**隔离**时，需要先在项目**设置**的**网络**中，将对方项目加入**允许其他项目连入**，见[隔离其他项目](./projects.mdx#隔离其他项目)。

这些地址仅在集群内有效，无法从互联网访问。

### 服务没有私有地址时

只主动向外连接的后台服务不需要私有地址。要让其他服务或公开域名连进来，先创建 Service。**私有网络**会显示可复制的命令，例如：

```sh
kubectl -n demo expose deployment web --port=8080
```

就绪检查使用数字端口时，命令会直接带上该端口。否则命令会显示 `--port=<port>`，运行前将 `<port>` 替换为应用监听的端口。

## 将端口开放到互联网

数据库、游戏服务器、MQTT 等非 HTTP 服务，通过对外端口让集群外的客户端连接。

<Steps>
<Step>

### 选择端口

进入服务**网络**中的**对外端口**，点击**开放端口**，在**端口**中选择要开放的端口。只能选择私有地址上的端口。

</Step>
<Step>

### 检查并应用

点击**检查变更**，确认后应用。

</Step>
<Step>

### 获取地址

列表会显示每个节点的地址和端口，例如 `203.0.113.7:5432`，旁边有复制按钮。如果显示**端口 5432 正在等待负载均衡器分配地址**，说明负载均衡器仍在处理，或节点上的这个端口已有其他服务占用。

</Step>
</Steps>

<Callout type="warn">
开放的端口前没有密码或 HTTPS 保护，互联网上任何人都能连接，服务需要自行验证连接者的身份。开放数据库时，界面会标注**数据库对外开放**。只有项目内的服务需要连接数据库时，改用私有地址。
</Callout>

ServiceLB 会在每个节点监听同一个端口号，因此整个集群内同一个端口号只能开放一次。同一项目内已有服务开放了相同端口时，Zeabur 会拒绝。

要关闭端口，点击对应行的**关闭**，检查后应用。

## 用连接规则限制入站和出站连接

**连接规则**上方显示当前谁能连接，例如 **web 只接受 1 个服务连入**，下方分为**入站**和**出站**两栏，列出允许、部分允许或阻止的对象。项目没有任何规则时，所有连接都允许。

点击**添加规则**，选择一种：

| 规则 | 效果 |
| --- | --- |
| **隔离这个服务** | 只有同一项目内的副本能连进来，这个服务也只能连接同一项目内的服务和 DNS，无法连接互联网。 |
| **允许来自公开域名的流量** | 允许 Traefik 将公开域名的请求转发进来。 |
| **允许某个服务连入…** | 选择同一项目内的一个服务，允许那个服务连进来。 |

规则可以叠加。常见组合是先**隔离这个服务**，再添加**允许来自公开域名的流量**和需要连进来的服务。

<Callout type="warn">
隔离后，添加**允许来自公开域名的流量**之前，服务的公开域名都无法访问。
</Callout>

要让隔离的服务连接外部 API，在同一页的 **IP 限制**中，将地址加入**能连到哪里**，见[限制入站和出站 IP](./ip-limits.mdx)。

要删除规则，点击规则名称进入**对象**页，在 YAML 视图中点击**删除**。

## 用 kubectl 完成相同操作

私有地址是普通的 ClusterIP Service，对外端口是 `LoadBalancer` Service，连接规则是普通的 NetworkPolicy。以下以项目 `demo` 为例。

### 私有地址

```yaml
apiVersion: v1
kind: Service
metadata:
  name: web
  namespace: demo
  labels:
    app.kubernetes.io/name: web
spec:
  selector:
    app.kubernetes.io/name: web
  ports:
    - name: http
      port: 8080
      targetPort: 8080
```

`selector` 要与 Deployment 的 Pod 标签一致。

### 对外端口

Zeabur 开放端口时会创建 `<Service 名称>-public-<端口>`，复制源 Service 的 `selector` 和对应端口，并将类型改为 `LoadBalancer`。标签 `app.kubernetes.io/name` 的值是服务名称，删除服务时会一并删除这个 Service。开放 `db` 的 5432 端口：

```yaml
apiVersion: v1
kind: Service
metadata:
  name: db-public-5432
  namespace: demo
  labels:
    app.kubernetes.io/name: db
spec:
  type: LoadBalancer
  selector:
    app.kubernetes.io/name: db
  ports:
    - name: postgres
      port: 5432
      targetPort: 5432
      protocol: TCP
```

删除这个 Service 即可关闭端口：

```sh
kubectl -n demo delete service db-public-5432
```

### 连接规则

Zeabur 创建的规则都带有 `app.kubernetes.io/managed-by: zeabur` 标签，名称为 `zeabur-<规则>-<服务>`，超过 63 个字符会截断。以下以项目 `api` 为例。

**隔离这个服务**：

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: zeabur-isolate-api
  namespace: demo
  labels:
    app.kubernetes.io/managed-by: zeabur
spec:
  podSelector:
    matchLabels:
      app.kubernetes.io/name: api
  policyTypes: [Ingress, Egress]
  ingress:
    - from:
        - podSelector: {}
  egress:
    - to:
        - podSelector: {}
    - to:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: kube-system
          podSelector:
            matchLabels:
              k8s-app: kube-dns
      ports:
        - protocol: UDP
          port: 53
        - protocol: TCP
          port: 53
```

**允许某个服务连入**，这里允许 `web` 连接 `api`：

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: zeabur-allow-web-api
  namespace: demo
  labels:
    app.kubernetes.io/managed-by: zeabur
spec:
  podSelector:
    matchLabels:
      app.kubernetes.io/name: api
  policyTypes: [Ingress]
  ingress:
    - from:
        - podSelector:
            matchLabels:
              app.kubernetes.io/name: web
```

**允许来自公开域名的流量**。规则允许两个位置的 Traefik：K3s 内置的 Traefik 位于 `kube-system`，Zeabur 安装程序安装的 Traefik 位于带有 `zeabur.com/platform: "true"` 标签的 Namespace：

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: zeabur-allow-ingress-api
  namespace: demo
  labels:
    app.kubernetes.io/managed-by: zeabur
spec:
  podSelector:
    matchLabels:
      app.kubernetes.io/name: api
  policyTypes: [Ingress]
  ingress:
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: kube-system
          podSelector:
            matchLabels:
              app.kubernetes.io/name: traefik
        - namespaceSelector:
            matchLabels:
              zeabur.com/platform: "true"
          podSelector:
            matchLabels:
              app.kubernetes.io/name: traefik
```

删除规则：

```sh
kubectl -n demo delete networkpolicy zeabur-isolate-api
```

## 确认结果

**私有网络**列出每个 Service 及其端口。**对外端口**列出每个节点的地址，数据库会标注**数据库对外开放**。**连接规则**列出应用到这个服务的规则名称，以及**入站**和**出站**各自允许的对象。

```sh
kubectl -n demo get service
kubectl -n demo get networkpolicy -l app.kubernetes.io/managed-by=zeabur
kubectl -n demo run probe --rm -it --restart=Never --image=busybox:1.37 -- wget -qO- -T 3 http://api:8080
```

在 `get service` 的 `TYPE` 列中，私有地址是 `ClusterIP`，对外端口是 `LoadBalancer`，`EXTERNAL-IP` 是节点地址。最后一行从同一项目内的临时副本连接 `api`。`api` 已隔离且未允许 `probe` 时，连接会在 3 秒后超时。从集群外运行 `nc -vz 203.0.113.7 5432`，确认对外端口可以连接。

## 遇到问题

| 界面或结果 | 处理方法 |
| --- | --- |
| **web 没有私有地址** | 运行界面上的 `kubectl expose` 命令，或应用上面的 Service。 |
| `kubectl expose` 返回 `couldn't find port via --port flag or introspection` | 容器没有声明端口。在 `--port=` 后填写应用监听的端口。 |
| 一直显示**正在等待负载均衡器分配地址** | 节点上的这个端口已有其他服务占用，或集群没有负载均衡器。更换端口，或请管理员检查 ServiceLB。 |
| 开放端口时提示已有服务开放了相同端口 | 同一项目内已经开放了这个端口号，先关闭已有的对外端口。 |
| 隔离后访问公开域名超时 | 添加**允许来自公开域名的流量**。 |
| 隔离后服务无法连接外部 API | 隔离后只允许连接同一项目内的服务和 DNS。在 **IP 限制**的**能连到哪里**中添加外部 API 的地址。 |
| 添加规则后，连接仍然畅通 | 集群的网络插件不支持 NetworkPolicy。 |
