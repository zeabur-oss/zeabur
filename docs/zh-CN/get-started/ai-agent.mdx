不熟悉 Linux 命令也能安装 Zeabur。把下面这段话发给 Claude Code、Codex 这类 AI Agent，它会连接你的服务器，下载并验证 installer、写好配置、完成安装，最后把首位管理员的注册链接交给你。

整个过程只有两件事需要你决定：用哪两个域名，以及看过安装计划后要不要开始。

## 先准备

- 一台服务器，条件见[快速开始的服务器要求](quickstart.mdx#准备服务器)。向云服务商租一台内存 4 GiB 以上的 Linux 服务器就可以。
- 自己电脑上装好的 AI Agent，例如 Claude Code 或 Codex。
- 两个域名，例如 `zeabur.example.com` 和 `login.example.com`，都有 DNS 记录指向这台服务器。还没有域名也没关系，AI Agent 会改用 sslip.io 的名称。

## 1. 让电脑能用密钥登录服务器

AI Agent 通过你电脑上的 SSH 连接服务器。先让这台电脑用密钥登录，就不必把密码交给 AI Agent。

- 很多云服务商在创建服务器时，就能填入 SSH 公钥。不知道公钥在哪里，可以让 AI Agent 帮你在电脑上生成密钥，再把公钥粘贴到云服务商的控制台。
- 服务器已经创建好、只能用密码登录时，在自己电脑的终端运行下面这行，自己输入一次密码：

```sh
ssh-copy-id <user>@<server>
```

把 `<user>@<server>` 换成云服务商给你的账号和地址，例如 `root@203.0.113.10`。

然后运行下面这行确认。没有要求输入密码就结束，就准备好了：

```sh
ssh <user>@<server> sudo true
```

## 2. 把这段话发给 AI Agent

在自己的电脑上打开 Claude Code 或 Codex，粘贴下面这段，并将 `<user>@<server>` 换成你的服务器：

```text
请帮我在 <user>@<server> 这台服务器上安装 Zeabur，通过 SSH 连接，需要 root 的命令用 sudo。

1. 按照 https://oss.zeabur.com/zh-CN/docs/zeabur/reference/releases 的“下载与验证可执行文件”，下载 https://github.com/zeabur-oss/zeabur/releases 上最新发行版的 zeabur-installer，并根据服务器的 `uname -m` 选择 linux-amd64 或 linux-arm64。验证 SHA256SUMS 的签名、文件的 SHA-256 和构建来源，三项都通过才解压。任何一项不通过就停下来告诉我，不要为了通过验证而修改验证参数。
2. 问我 Zeabur 和登录（Identity）要用的两个域名。我没有域名时，用 zeabur.<公网地址>.sslip.io 和 login.<公网地址>.sslip.io；服务器只有私有地址时，改用 local 模式。按照 https://oss.zeabur.com/zh-CN/docs/zeabur/install/config-file 写好 /etc/zeabur-installer/config.yaml。
3. 运行 sudo zeabur-installer plan，用通俗的话把变更、警告和未通过的检查整理给我看，等我确认后再继续。
4. 我同意后运行 sudo zeabur-installer apply。中途失败时，先修复原因，再用同一份配置重新运行。
5. 安装完成后运行 sudo zeabur-installer doctor，汇报结果。
6. 把首位管理员的注册链接原样交给我，不要自己打开，也不要自己注册通行密钥。

其他细节见 https://oss.zeabur.com/llms.txt。
```

## 3. 回答它的两个问题

**用哪两个域名**：回复你准备好的两个域名。没有域名就回复“没有”，它会用 sslip.io 的名称。

**安装计划行不行**：它会列出要做的变更、警告和未通过的检查。

- 有未通过的检查，就让它说明原因并修好，再重新列一次。
- 只有警告可以继续，例如磁盘没有加密。
- 没问题就回复“可以安装”。安装大约需要 10 到 20 分钟。

## 4. 自己打开注册链接

安装完成后，AI Agent 会把首位管理员的注册链接交给你。用自己的浏览器打开，注册通行密钥，再登录 Zeabur。步骤见[注册首位管理员](quickstart.mdx#注册首位管理员)。

<Callout type="warn">
首位管理员的注册链接会创建管理员账号，谁先打开谁就能控制整个集群。只让 AI Agent 把链接交给你，不要让它自己打开。
</Callout>

用 local 模式安装时，要先把服务器的证书颁发机构导入浏览器或系统并设为信任，才能注册通行密钥。可以让 AI Agent 把 `/var/lib/rancher/zeabur-installer/local-ca.crt` 复制到你的电脑。

## 想自己在安装界面上操作

可以让 AI Agent 改用[快速开始的一行命令](quickstart.mdx#用一行命令)，把带有令牌的链接交给你，由你自己打开并完成五个步骤。
