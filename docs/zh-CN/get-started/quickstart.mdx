三种方式装出的 Zeabur 都一样。区别在于谁来动手，以及你想看到多少细节。

| 你的情况 | 选这个 |
| --- | --- |
| 想让 AI 助手代劳 | [交给 Agent 安装或迁移](../install/agent.mdx) |
| 有一台全新的 Linux 服务器 | [用 Zeatend 安装](../install/one-command.mdx) |
| 已经在运行 Kubernetes 集群 | [将 Zeabur 安装到已有集群](../install/existing-cluster.mdx) |

三种方式最后都是同一条 `helm install`。Helm 是 Kubernetes 的安装工具。Kubernetes 是在一台或多台服务器上运行容器的开源系统，集群就是一组由它管理的服务器。Zeatend 会在新服务器上装好 Kubernetes。

只想在自己的电脑上查看集群，而不安装到集群中，见 [Zeabur Desktop](../install/desktop.mdx)。
