title: Zeabur Desktop：在自己的电脑上打开集群
description: 在 macOS、Windows 或 Linux 上安装 Zeabur Desktop，为 kubeconfig 里的任何集群打开 Zeabur 开源版，并保持最新版本。
---

Zeabur Desktop 会列出你电脑上 kubeconfig 文件里的 context，你选哪一个，它就在新窗口里为那个集群打开 Zeabur 开源版。它做的事和 `zeaburctl ui` 一样，只是不用打开终端。

## 用 Homebrew 安装

在装了 [Homebrew](https://brew.sh) 的 Apple 芯片 Mac 上，不用自己下载，直接用它安装：

```sh
brew tap zeabur-oss/tap
brew install --cask zeabur-oss/tap/zeabur-desktop
```

Homebrew 安装的是发布页面上同一个已签名的 `.dmg`，并用该版本的校验和核对文件。

想试用最新的预发布版本，就安装 `zeabur-desktop@beta`。它和 `zeabur-desktop` 是同一个 App，所以要先卸载 `zeabur-desktop`：

```sh
brew install --cask zeabur-oss/tap/zeabur-desktop@beta
```

## 下载

在 [GitHub Releases](https://github.com/zeabur-oss/zeabur/releases) 选择一个版本，下载适合你电脑的文件：

| 电脑 | 文件 |
|---|---|
| Apple 芯片的 Mac | `zeabur-desktop-v<version>-darwin-arm64.dmg` |
| x64 的 Windows | `zeabur-desktop-v<version>-windows-amd64-setup.exe`；不想安装就用 `-portable.exe` |
| Debian 或 Ubuntu | `zeabur-desktop-v<version>-linux-<arch>.deb` |
| Fedora、RHEL 或 openSUSE | `zeabur-desktop-v<version>-linux-<arch>.rpm` |
| 其他 Linux | `zeabur-desktop-v<version>-linux-<arch>.AppImage` |

Linux 的 `<arch>` 是 `amd64` 或 `arm64`。没有 Intel Mac 和 Arm 版 Windows 的版本。每个版本的 `SHA256SUMS` 也包含这些文件，验证方法见[发行文件与验证](../reference/releases.mdx)。

## 安装

- **macOS**：打开 `.dmg`，把 Zeabur 开源版拖进“应用程序”。
- **Windows**：运行 `-setup.exe`。它只为你的账户安装，不需要管理员权限。
- **Debian 或 Ubuntu**：`sudo apt install ./zeabur-desktop-v<version>-linux-<arch>.deb`
- **Fedora、RHEL 或 openSUSE**：`sudo dnf install ./zeabur-desktop-v<version>-linux-<arch>.rpm`，openSUSE 用 `zypper install`。
- **AppImage**：用 `chmod +x` 让文件可以运行，再运行它。

## 更新

Zeabur Desktop 每次启动都会检查有没有新版本。有的话，侧边栏会出现“更新到 0.3.1”这样的按钮。想自己检查时，点击侧边栏底部版本号旁的“检查更新”；在 macOS 上也可以选择“Zeabur 开源版 > 检查更新…”。

更新会先列出更新内容，你点击“更新并重启”后才会安装。接着 Zeabur 开源版会关闭窗口，以新版本重新启动。正式版本只会收到较新的正式版本。预发布版本（例如 `0.3.0-beta.1`）也会收到较新的预发布版本，之后再收到对应的正式版本。

macOS 的 App、用 Windows 安装程序装的 Zeabur 开源版和 AppImage 都能自行更新，用 Homebrew 装的 App 也一样；`brew upgrade --greedy` 也能更新它。`.deb`、`.rpm` 和免安装的 `.exe` 不行：Zeabur 开源版会告诉你有新版本，请到发布页面下载，用第一次安装的方式再装一次。
