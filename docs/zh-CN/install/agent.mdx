Claude Code 或 Codex 这类 Coding Agent 可以替你按安装步骤操作。它读的页面和你一样，会自己运行命令，遇到需要你决定或付费的地方就停下来。

## 粘贴这段提示词

```text
按照 https://oss.zeabur.com/zh-CN/docs/zeabur/install/one-command.md 把 Zeabur 安装到我的服务器上。
如果服务器已经在运行 Kubernetes，改为按照 https://oss.zeabur.com/zh-CN/docs/zeabur/install/existing-cluster.md 安装。
```

这两个网址分别指向[用 Zeatend 安装](one-command.mdx)和[将 Zeabur 开源版安装到已有集群](existing-cluster.mdx)的 Markdown 版。在能通过 SSH 连接服务器的电脑上运行 Agent，并告诉它服务器的地址。

## Agent 会做的事

1. 检查服务器，修改任何内容前先询问你。
2. 服务器还没有 Kubernetes 时，用 Zeatend 装好。
3. 用一条 `helm install` 安装 Zeabur。
4. 给你 Zeabur 的网址，以及创建管理员账号的链接。

## 你需要自己做的事

- 准备服务器并付费。
- 想用自己的域名而不是 sslip.io 地址时，把域名的 DNS 记录指向服务器。
- 打开链接，创建通行密钥。通行密钥只能由你在自己的设备上创建。

## 从 zeabur.com 迁移过来

想把项目一起迁移过来，在提示词后面加上：“然后按照 https://oss.zeabur.com/zh-CN/docs/zeabur/get-started/from-zeabur-com.md 把我在 zeabur.com 的服务迁移过来。”这个文件是[从 zeabur.com 过来](../get-started/from-zeabur-com.mdx)的 Markdown 版。Agent 会列出你的服务、备份数据库，在 Zeabur 中重建服务，再还原数据。
