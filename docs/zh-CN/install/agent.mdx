## 完成后你会得到

- 一台你自己的服务器，上面运行着 Zeabur。
- Zeabur 的网址，以及第一次登录的方式。
- 如果要迁移，zeabur.com 上的服务和数据也会在新服务器上运行。

## 以后的流程

1. 你把一段提示词粘贴到 Claude Code 或 Codex。提示词只有一句话，里面附上这个页面的网址。
2. Agent 读这个页面，问你要用哪家的服务器、哪个套餐，并列出价格。你确认之后，它才会购买。
3. Agent 用 Zeatend 在新服务器上装好 Kubernetes 和 Zeabur。
4. 要迁移时，Agent 按照 zeabur.com 的[迁移指南](https://zeabur.com/zh-CN/blogs/migrate-from-zeabur)列出你的服务、备份数据库，再在 Zeabur 上重建服务、还原数据。
5. 最后，Agent 会告诉你 Zeabur 的网址，以及第一次怎么登录。

## 你自己要做的事

Agent 会在这几步停下来，等你处理：

- 确认要买的服务器和价格。
- 付款。
- 修改域名的 DNS，把网址指向新服务器。
