根据你的情况选一页开始。每条路线都会带你装好 Zeabur 开源版，并用通行密钥登录。

| 你的情况 | 从这一页开始 |
| --- | --- |
| 想让 Claude Code 或 Codex 代劳 | [交给 Agent 安装或迁移](install/agent.mdx) |
| 有一台全新的 Linux 服务器 | [用 Zeatend 安装](install/one-command.mdx) |
| 已经在运行 Kubernetes 集群 | [将 Zeabur 开源版安装到已有集群](install/existing-cluster.mdx) |
| 正在用 Zeabur，想把服务迁移过来 | [从 Zeabur 过来](get-started/from-zeabur-com.mdx) |

Kubernetes 是在一台或多台服务器上运行容器的开源系统，集群就是一组由它管理的服务器。Zeatend 会在新服务器上装好 Kubernetes。每条路线最后都用同一条 `helm install` 安装 Zeabur 开源版，Helm 是 Kubernetes 的安装工具。

只想在自己的电脑上查看集群，而不安装到集群中，见 [Zeabur Desktop](install/desktop.mdx)。
