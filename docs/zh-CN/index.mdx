用 Zeabur 查看 Kubernetes 中的服务、日志和域名。调整配置时，先**检查变更**再应用。根据现有环境选择起点。

## 从一台服务器开始

准备一台使用 systemd 的 Linux 服务器、root 权限，以及指向这台主机的登录和管理域名。Zeabur Installer 的网页界面会引导你逐步检查服务器、选择组件，再安装 K3s（或 RKE2）、Zeabur Identity 和 Zeabur。

完成后，界面会显示 Zeabur 网址和首位管理员的通行密钥注册链接。登录后就能创建第一个项目。

[在一台服务器上安装 Zeabur](get-started/quickstart.mdx)

## 使用已有的 Kubernetes 集群

准备集群管理权限、Helm，以及 kube-apiserver 已信任的 Zeabur Identity。Zeabur 网址必须能通过 HTTPS 打开，浏览器才会提供通行密钥。

完成后，用通行密钥登录 Zeabur，在**项目**中找到已有的 Namespace，或新建项目部署服务。

[将 Zeabur 安装到已有集群](get-started/install.mdx)
