---
title: Let an agent install for you
description: Paste one prompt into Claude Code or Codex, and it installs Zeabur OSS on a server for you by following these docs.
---

An agent such as Claude Code or Codex can follow the install steps for you. It reads the same pages you would, runs the commands, and stops where a decision or a payment is yours.

## Paste this prompt

```text
Install Zeabur OSS on my server by following https://oss.zeabur.com/docs/zeabur/install/one-command.md.
If the server already runs Kubernetes, follow https://oss.zeabur.com/docs/zeabur/install/existing-cluster.md instead.
```

Each address points to the Markdown copy of a docs page: [Install with Zeatend](one-command.mdx) and [Install Zeabur OSS in an existing cluster](existing-cluster.mdx). Run the agent on a computer that can reach the server over SSH, and tell it the server's address.

## What the agent does

1. Checks the server and asks you before it changes anything.
2. Sets up Kubernetes with Zeatend, unless the server already runs it.
3. Installs Zeabur OSS with one `helm install`.
4. Gives you Zeabur OSS's address and the link that creates your admin account.

## What you do yourself

- Get the server and pay for it.
- To use your own domain instead of an sslip.io address, point its DNS records at the server.
- Open the link and create your passkey. Only you can make it, on your own device.

## Coming from Zeabur

To move a project too, add to the prompt: "Then move my Zeabur services by following https://oss.zeabur.com/docs/zeabur/get-started/from-zeabur-com.md." That file is the Markdown copy of [Coming from Zeabur](../get-started/from-zeabur-com.mdx). The agent lists your services, backs up the databases, creates the services again in Zeabur OSS, and restores the data.
