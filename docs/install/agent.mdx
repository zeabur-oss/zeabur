---
title: Let an agent install for you
description: Paste one prompt into Claude Code or Codex, and it installs Zeabur on a server for you by following these docs.
---

An agent such as Claude Code or Codex can follow the install steps for you. It reads the same pages you would, runs the commands, and stops where a decision or a payment is yours.

## Paste this prompt

```text
Install Zeabur on my server by following https://oss.zeabur.com/docs/zeabur/install/one-command/.
If the server already runs Kubernetes, follow https://oss.zeabur.com/docs/zeabur/install/existing-cluster/ instead.
```

Run the agent on a computer that can reach the server over SSH, and tell it the server's address.

## What the agent does

1. Checks the server and asks you before it changes anything.
2. Sets up Kubernetes with Zeatend, unless the server already runs it.
3. Installs Zeabur with one `helm install`.
4. Gives you Zeabur's address and the link that creates your admin account.

## What you do yourself

- Get the server and pay for it.
- To use your own domain instead of an sslip.io address, point its DNS records at the server.
- Open the link and create your passkey. Only you can make it, on your own device.

## Coming from zeabur.com

To move a project too, add to the prompt: "Then move my zeabur.com project by following https://zeabur.com/blogs/migrate-from-zeabur". The agent lists your services, backs up the databases, creates the services again in Zeabur, and restores the data.
