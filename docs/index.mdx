title: Get started with Zeabur
description: Start managing services on a single server or an existing Kubernetes cluster.
---

Use Zeabur to see the services, logs, and domains in your Kubernetes cluster. When you change a setting, **Review changes** comes before anything is applied. Pick the starting point that matches your environment.

## Start with one server

You need a Linux server that uses systemd, root access, and sign-in and admin domains that point to the host. The Zeabur Installer web interface checks the server step by step, lets you choose components, and installs K3s (or RKE2), Zeabur Identity, and Zeabur.

When it finishes, the screen shows the Zeabur address and a passkey registration link for the first admin. After you sign in, you can create your first project.

[Install Zeabur on a single server](get-started/quickstart.mdx)

## Use an existing Kubernetes cluster

You need cluster admin access, Helm, and a Zeabur Identity that kube-apiserver already trusts. The Zeabur address must open over HTTPS so the browser offers passkeys.

When the install finishes, sign in to Zeabur with a passkey, then find an existing Namespace under **Projects** or add a project to deploy services.

[Install Zeabur in an existing cluster](get-started/install.mdx)
