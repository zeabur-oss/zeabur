Use Zeabur OSS to see the services, logs, and domains in your Kubernetes cluster. When you change a setting, **Review changes** comes before anything is applied. For what Zeatend, Zeabur Identity, Zeabur Catalog and Zeabur Builder each do, see the [overview](https://oss.zeabur.com/docs/overview/).

Start on the page that fits what you have. Each path takes you through the install until you sign in to Zeabur OSS with a passkey.

| What you have | Start here |
| --- | --- |
| You want Claude Code or Codex to do it | [Let an agent install for you](install/agent.mdx) |
| A new Linux server | [Install with Zeatend](install/one-command.mdx) |
| A Kubernetes cluster you already run | [Install Zeabur OSS in an existing cluster](install/existing-cluster.mdx) |
| Services on Zeabur that you want to move | [Coming from Zeabur](get-started/from-zeabur-com.mdx) |

Kubernetes is open-source software that runs containers on one or more servers, and a cluster is a set of servers it manages. Zeatend sets up Kubernetes on a new server. Each path installs Zeabur OSS with the same `helm install`. Helm is Kubernetes' install tool.

To look at a cluster from your own computer, without installing anything in it, see [Zeabur Desktop](install/desktop.mdx).
