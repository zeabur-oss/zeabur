Use Zeabur to see the services, logs, and domains in your Kubernetes cluster. When you change a setting, **Review changes** comes before anything is applied. Pick the starting point that matches your environment.

## Start with one server

Installing Zeabur on a bare server comes back with Zeatend. Until then, install Zeabur on a cluster you already have.

[Install Zeabur on a server](get-started/quickstart.mdx)

## Use an existing Kubernetes cluster

You need cluster admin access and Helm. The chart installs Zeabur Identity too, and kube-apiserver must trust it, as [Install Zeabur in an existing cluster](install/existing-cluster.mdx) shows. The Zeabur address must open over HTTPS so the browser offers passkeys.

When the install finishes, sign in to Zeabur with a passkey, then find an existing Namespace under **Projects** or add a project to deploy services.

[Install Zeabur in an existing cluster](install/existing-cluster.mdx)
