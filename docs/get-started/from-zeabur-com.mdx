## What is different

- **The server is yours.** Zeabur runs on your own server. You decide where your services run and how big the server is.
- **You pay the server provider.** Zeabur is open-source software. It doesn't charge you and has no usage billing. You pay only for the server, to the cloud provider or data center you chose.
- **You look after it.** You or your team [upgrade Zeabur](../upgrade/steps.mdx), [back up the cluster](../cluster/backups.mdx), and maintain the server.
- **You invite the members.** Each person signs in with their own passkey and can use only the projects you give them. See [Invite members and assign project permissions](../cluster/members.mdx).
- **Projects don't move over by themselves.** Deploy each service again in Zeabur from the same Git repository, image, or template. Set its variables again, and copy database and disk data yourself. Then point the domain at the new address.

## Where to start

Zeabur runs on Kubernetes, open-source software that runs containers on one or more servers. [Install Zeabur on a server](quickstart.mdx) shows the ways to install it and which one fits you. Then [deploy your first service](first-project.mdx).
