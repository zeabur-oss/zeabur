不熟 Linux 指令也能安裝 Zeabur。把下面那段話貼給 Claude Code、Codex 這類 AI Agent，它會連到你的伺服器，下載並驗證 installer、寫好設定、完成安裝，最後把第一位管理員的註冊連結交給你。

過程中只有兩件事要你決定：要用哪兩個網域，以及看過安裝計畫後要不要開始。

## 先準備

- 一台伺服器，條件見[快速開始的伺服器條件](quickstart.mdx#先準備伺服器)。向雲端主機商租一台記憶體 4 GiB 以上的 Linux 主機就可以。
- 自己電腦上裝好的 AI Agent，例如 Claude Code 或 Codex。
- 兩個網域，例如 `zeabur.example.com` 和 `login.example.com`，都有 DNS 紀錄指向這台伺服器。還沒有網域也沒關係，AI Agent 會改用 sslip.io 的名稱。

## 1. 讓電腦能用金鑰登入伺服器

AI Agent 透過你電腦上的 SSH 連到伺服器。先讓這台電腦用金鑰登入，就不必把密碼交給 AI Agent。

- 很多主機商在建立主機時，就能貼上 SSH 公鑰。不知道公鑰在哪，可以請 AI Agent 幫你在電腦上建立金鑰，再把公鑰貼到主機商的控制台。
- 主機已經建好、只能用密碼登入時，在自己電腦的終端機執行下面這行，自己輸入一次密碼：

```sh
ssh-copy-id <user>@<server>
```

把 `<user>@<server>` 換成主機商給你的帳號和位址，例如 `root@203.0.113.10`。

接著執行下面這行確認。沒有要你輸入密碼就結束，就準備好了：

```sh
ssh <user>@<server> sudo true
```

## 2. 把這段話貼給 AI Agent

在自己的電腦開啟 Claude Code 或 Codex，貼上下面這段，並將 `<user>@<server>` 換成你的伺服器：

```text
請幫我在 <user>@<server> 這台伺服器安裝 Zeabur，用 SSH 連線，需要 root 的指令用 sudo。

1. 依 https://oss.zeabur.com/zh-TW/docs/zeabur/reference/releases 的「下載與驗證執行檔」，下載 https://github.com/zeabur-oss/zeabur/releases 上最新發行版的 zeabur-installer，並依伺服器的 `uname -m` 選擇 linux-amd64 或 linux-arm64。驗證 SHA256SUMS 的簽章、檔案的 SHA-256 和建置來源，三項都通過才解壓縮。任何一項沒通過就停下來告訴我，不要為了讓驗證通過而修改驗證參數。
2. 問我 Zeabur 和登入（Identity）要用的兩個網域。我沒有網域時，用 zeabur.<公開位址>.sslip.io 和 login.<公開位址>.sslip.io；伺服器只有私有位址時，改用 local 模式。依 https://oss.zeabur.com/zh-TW/docs/zeabur/install/config-file 寫好 /etc/zeabur-installer/config.yaml。
3. 執行 sudo zeabur-installer plan，用白話把變更、警告和沒通過的檢查整理給我看，等我確認可以再繼續。
4. 我同意後執行 sudo zeabur-installer apply。中途失敗時，先修好原因，再用同一份設定重新執行。
5. 安裝完成後執行 sudo zeabur-installer doctor，回報結果。
6. 把第一位管理員的註冊連結原樣交給我，不要自己開啟，也不要自己註冊通行密鑰。

其他細節見 https://oss.zeabur.com/llms.txt。
```

## 3. 回答它的兩個問題

**要用哪兩個網域**：回覆你準備好的兩個網域。沒有網域就回覆「沒有」，它會用 sslip.io 的名稱。

**安裝計畫可不可以**：它會列出要做的變更、警告和沒通過的檢查。

- 有沒通過的檢查，就請它說明原因並修好，再重新列一次。
- 只有警告可以繼續，例如磁碟沒有加密。
- 沒問題就回覆「可以安裝」。安裝約需 10 到 20 分鐘。

## 4. 自己開啟註冊連結

安裝完成後，AI Agent 會交給你第一位管理員的註冊連結。用自己的瀏覽器開啟，註冊通行密鑰，再登入 Zeabur。步驟見[註冊第一位管理員](quickstart.mdx#註冊第一位管理員)。

<Callout type="warn">
第一位管理員的註冊連結會建立管理員帳號，誰先開啟就由誰掌控整個叢集。只讓 AI Agent 把連結交給你，不要讓它自己開啟。
</Callout>

用 local 模式安裝時，要先把伺服器的憑證授權單位匯入瀏覽器或系統並設為信任，才能註冊通行密鑰。可以請 AI Agent 把 `/var/lib/rancher/zeabur-installer/local-ca.crt` 複製到你的電腦。

接著可以[部署第一個服務](first-project.mdx)。

## 想自己在安裝介面上點選

可以請 AI Agent 改用[快速開始的一行指令](quickstart.mdx#用一行指令)，把含權杖的連結交給你，由你自己開啟並完成五個步驟。
