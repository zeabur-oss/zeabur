三種方式裝出來的 Zeabur 開源版都一樣。差別在於誰來動手，以及你想看到多少細節。

| 你的情況 | 選這個 |
| --- | --- |
| 想讓 AI 助手代勞 | [交給 Agent 安裝或搬家](../install/agent.mdx) |
| 有一台全新的 Linux 伺服器 | [用 Zeatend 安裝](../install/one-command.mdx) |
| 已經在跑 Kubernetes 叢集 | [把 Zeabur 開源版裝進既有叢集](../install/existing-cluster.mdx) |

三種方式最後都是同一個 `helm install`。Helm 是 Kubernetes 的安裝工具。Kubernetes 是在一台或多台伺服器上執行容器的開源系統，叢集就是一組由它管理的伺服器。Zeatend 會在新伺服器上裝好 Kubernetes。

只想在自己的電腦上看看叢集，不必安裝到叢集裡，見 [Zeabur Desktop](../install/desktop.mdx)。
