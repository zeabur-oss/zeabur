---
title: 在一台伺服器安裝 Zeabur
description: Zeabur 用 Helm chart 裝進既有的 Kubernetes 叢集。在全新的伺服器上安裝，會隨 Zeatend 回來。
---

Zeabur 用 Helm chart 裝進既有的 Kubernetes 叢集，步驟見[把 Zeabur 裝進既有叢集](../install/existing-cluster.mdx)。

在全新的伺服器上安裝 Zeabur，之後會回來。[Zeatend](https://github.com/zeabur-oss/zeatend) 負責在伺服器上裝好 Kubernetes，再由一行安裝指令裝上 Zeabur。進度見 [zeabur-oss/zeabur#430](https://github.com/zeabur-oss/zeabur/issues/430)。
