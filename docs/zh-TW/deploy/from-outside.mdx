---
title: 從自己的電腦或 CI 連線
description: 用 zeaburctl 和 API 權杖，在自己的電腦上用 psql 或 DBeaver 開資料庫，或從 GitHub Actions 上傳資料夾。
---

`zeaburctl connect` 和 `zeaburctl up` 跟 kubectl 一樣用 kubeconfig 操作叢集，只經由 TCP 6443 上的 kube-apiserver 連進去，所以資料庫和建置用的 registry 都不需要公開位址。這頁用 [API 權杖](../reference/api-tokens.mdx)做 kubeconfig，在自己的電腦和 CI 都能用，能做的事也只限於權杖的角色。

範例用專案 `shop`、PostgreSQL 資料庫 `orders` 和服務 `web`。

## 開始前

- 電腦上已經裝好 [zeaburctl](../reference/zeaburctl.mdx)。
- 管理員已經建立 API 權杖，並讓它在 `shop` 是**開發者**。**檢視者**權杖不能連線，也不能上傳。見[建立權杖](../reference/api-tokens.mdx#建立權杖)。
- 你的電腦或 CI runner 連得到 kube-apiserver 的 TCP 6443。
- 要上傳資料夾的話，叢集裡要裝好 Zeabur Builder。

## 把權杖做成 kubeconfig

權杖視窗裡的 kubeconfig，`server` 是空的。先存成檔案，再填上 kube-apiserver 在 6443 連接埠的位址。位址怎麼找，見[把權杖做成 kubeconfig](../reference/api-tokens.mdx#把權杖做成-kubeconfig)。

```sh
chmod 600 deploy-shop.yaml
kubectl config set-cluster zeabur --server=https://203.0.113.10:6443 --kubeconfig deploy-shop.yaml
export KUBECONFIG=$PWD/deploy-shop.yaml
kubectl auth whoami
```

權杖只在一個專案有角色時，kubeconfig 一開始就在那個專案，不加 `--project` 時 zeaburctl 也用它。權杖在好幾個專案都有角色時，每個指令都要加 `--project shop`。

## 在自己的電腦上開資料庫

```sh
zeaburctl connect orders --project shop --port 15432
```

指令會把 `127.0.0.1:15432` 接到資料庫，並印出連線字串：

```text
Forwarding 127.0.0.1:15432 to orders in shop. Press Ctrl-C to stop.
postgresql://app:<password>@127.0.0.1:15432/app
```

使用期間讓指令一直執行，用完按 Ctrl-C 結束，叢集不會有任何變動。加上 `--port`，每次都用同一個本機連接埠，用戶端裡存好的連線就能繼續用；不加的話，指令會挑一個空著的連接埠。

- **psql**：把連線字串加上引號交給 `psql`，例如 `psql 'postgresql://app:<password>@127.0.0.1:15432/app'`。
- **DBeaver**：新增 PostgreSQL 連線，主機填 `127.0.0.1`，連接埠填 `15432`，資料庫、使用者名稱和密碼照連線字串填。

每種引擎都會印出連線字串：MySQL 和 MariaDB 是 `mysql://`，MongoDB 是 `mongodb://`，Dragonfly 是 `redis://`。服務也能連，`zeaburctl connect web:8080` 會印出 `127.0.0.1:52341` 這樣的本機位址。細節見 [`connect`](../reference/zeaburctl.mdx#connect)。

## 從 GitHub Actions 上傳資料夾

`zeaburctl up` 會打包資料夾，經由 kube-apiserver 送到建置用的 registry，再開始建置服務。服務不存在時，指令會建立它。

1. 把 kubeconfig 存成 repository 的 secret，不要放進 repository：

   ```sh
   gh secret set KUBECONFIG_DATA < deploy-shop.yaml
   ```

2. 加一個 workflow，例如 `.github/workflows/deploy.yml`：

   ```yaml
   name: Deploy
   on:
     push:
       branches: [main]
   jobs:
     deploy:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - name: Install zeaburctl
           env:
             GH_TOKEN: ${{ github.token }}
           run: |
             gh release download --repo zeabur-oss/zeabur \
               --pattern 'zeaburctl-v*-linux-amd64.tar.gz' --pattern SHA256SUMS
             sha256sum --check --ignore-missing SHA256SUMS
             tar -xzf zeaburctl-v*-linux-amd64.tar.gz zeaburctl
             sudo install zeaburctl /usr/local/bin/
         - name: Upload
           env:
             KUBECONFIG_DATA: ${{ secrets.KUBECONFIG_DATA }}
           run: |
             export KUBECONFIG="$RUNNER_TEMP/kubeconfig"
             (umask 077; printf '%s' "$KUBECONFIG_DATA" > "$KUBECONFIG")
             zeaburctl up . --project shop --service web --port 8080
   ```

`gh release download` 不指定 tag 時會下載最新版。要固定版本，就在 `download` 後面加上 tag，例如 `v0.3.3`。要一併驗證簽章，見[發行檔與驗證](../reference/releases.mdx)。

在 CI 裡指令不會發問，所以一定要給 `--service`；kubeconfig 一開始不在某個專案時，也要給 `--project`。`--port` 只對新服務有用，設定應用程式監聽的連接埠；新服務沒有設定的話，就不接受連線。服務已經存在時，指令不改它的建置設定。資料夾上傳完、建置開始後，指令就結束，建置完成時服務會部署新的建置結果。

## 連不上時

| 看到什麼 | 原因與處理 |
|---|---|
| 指令等了一陣子，接著說連不到叢集 | 這台機器連不到 TCP 6443。請在伺服器的防火牆或雲端供應商的安全群組開放這個連接埠。GitHub 代管的 runner 沒有固定位址，可能要改用自架 runner，或用 VPN 連到伺服器。 |
| 錯誤說憑證對這個名稱或位址無效 | API 憑證沒有涵蓋 `server` 裡的位址。把位址加到 K3s 或 RKE2 設定檔的 `tls-san`（Zeatend 是 `host.tlsSan`），再重新啟動 K3s 或 RKE2。 |
| `not allowed to forward a port to zot/zot:5000` | 權杖在任何專案都不是**開發者**，或是建置用的 registry 在上次儲存權杖權限之後才安裝。請管理員在權杖旁選**更多** → **變更權限**，再儲存一次。見[建置用 registry 裡的映像檔](../reference/permissions.mdx#建置用-registry-裡的映像檔)。 |
| `not allowed to forward a port to shop/…` | 權杖在這個專案是**檢視者**。請管理員改成**開發者**。 |
| `Name the project with --project` | 權杖在好幾個專案都有角色，kubeconfig 一開始不在任何專案。請加上 `--project`。 |
| `Zeabur Builder is not installed in this cluster` | 安裝 Zeabur Builder，或改成部署映像檔，不上傳資料夾。 |
| `401 Unauthorized` | 權杖過期或已被刪除。更新權杖後，重新存一次 kubeconfig。 |
