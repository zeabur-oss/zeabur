打開 **叢集** → **備份**，先設定 **備份存放位置**，再設定 **排程**。按 **立即備份** 跑一次，等 **備份紀錄** 顯示 **成功**，就確定備份能用了。

叢集備份由 Velero 執行，把選定 Namespace 的 Kubernetes 物件和磁碟區裡的檔案存到 S3 相容儲存。PostgreSQL、MongoDB 這類資料庫有自己的備份，在各資料庫的 **備份** 分頁設定，見[部署資料庫](../deploy/databases.mdx)；只想備份單一服務的磁碟區，可以用 [K8up 磁碟區備份](../configure/volumes.mdx)。

## 開始之前

- 叢集裝了 Velero。畫面顯示 **備份需要 Velero** 時，按 **安裝 Velero**，照[安裝元件](./components.mdx)裝好。
- 準備 S3 相容的儲存貯體、端點和金鑰，或先登錄 [S3 目的地](./s3-destinations.mdx)。
- 你能在 Velero 的 Namespace 讀取和建立備份位置、排程、備份和 Secret。需要時先按 **暫時使用管理員權限**。
- 要還原時，準備一台裝了 `velero` 命令列工具、能連到目標叢集的電腦。

<Callout type="warn">
備份要存在叢集以外的儲存，例如 Cloudflare R2、Backblaze B2 或 AWS S3。存在同一個叢集裡的話，叢集遺失時備份也會一起消失；端點看起來在叢集裡時，表單會提醒。
</Callout>

## 設定存放位置

<Steps>
<Step>

### 選擇儲存貯體

在 **備份存放位置** 按 **設定** 或 **編輯**。已登錄 S3 目的地時，可以從選單選它；選單預設是 **手動輸入**。

手動輸入時填 **儲存貯體**、**存取金鑰 ID** 和 **私密存取金鑰**。用 AWS S3 時 **端點** 留白；R2、B2 或 MinIO 填它們的 S3 位址。**區域** 留白時是 `us-east-1`。**資料夾** 選填，可以讓這些備份和其他檔案分開。

編輯既有設定時，兩個金鑰都留白就沿用目前的金鑰；要換就兩個一起填。

</Step>
<Step>

### 檢查並等待連線結果

按 **檢查變更**，確認儲存貯體、端點，以及要新增或修改的備份位置和儲存金鑰，再套用。

回到 **備份存放位置**，等 **狀態** 從 **尚未檢查** 變成 **連得上**。顯示 **連不上** 時，先核對儲存貯體、端點和金鑰，再設定排程。

</Step>
</Steps>

## 設定排程並跑一次備份

1. 在 **排程** 選每天執行的 **時間**（UTC 整點）和 **保留天數**。新排程預設每天 03:00（UTC）、保留 7 天；保留天數可填 1 到 365。
2. 在 **範圍** 選 **整個叢集**，或選 **選定的專案** 並至少勾一個專案。**整個叢集** 也包括之後新增的專案和 Namespace。
3. 按 **檢查變更**，確認執行時間和範圍後套用。Zeabur 會建立或修改名為 `zeabur` 的 Velero Schedule，並開啟磁碟區檔案備份。
4. 按 **立即備份**，檢查後套用。這次備份照剛設定的範圍和保留天數執行，不用等排程。
5. 在 **備份紀錄** 找到這筆，等狀態從 **執行中** 變成 **成功**，再看紀錄列出的項目數和 **保留到** 的日期。

在 Zeabur 以外建立的排程會標示 **在 Zeabur 以外設定**，要回到原本建立的地方修改。

## 從備份還原

Zeabur 沒有還原的操作，還原要用 Velero 命令列工具。在 **備份紀錄** 複製要用的備份名稱，確認 `velero` 連到的是要還原的叢集，而且這個叢集的 Velero 設定了同一個備份存放位置。

```sh title="啟動 Velero 還原"
velero restore create --from-backup <backup>
```

把 `<backup>` 換成備份名稱。Velero 會還原這份備份裡的所有物件和磁碟區檔案。

還原後，到專案確認服務的副本都就緒、磁碟區掛上且資料正確，再開啟應用程式測試。用資料庫自己備份的資料，照該資料庫的還原步驟處理。

## 常見失敗

- **連不上**：核對儲存貯體、端點、區域和金鑰，並看位置下方 Velero 的訊息。
- 沒有 **立即備份**：要先有 Zeabur 建立的排程，而排程要先有存放位置。
- **部分失敗**：有些物件或磁碟區檔案沒有複製到，其餘的已存好。用 `velero backup describe <backup> --details` 查看失敗的項目，處理後再備份一次。
- 畫面說備份途中 Velero 重新啟動：下一次會照排程執行，也可以按 **立即備份** 補一次。
- **磁碟區** 顯示 **只備份物件，不複製磁碟區裡的檔案**：這是在 Zeabur 以外建立的排程，要到原本的設定開啟 `defaultVolumesToFsBackup`。
- 變更已過期：重新 **檢查變更**。

## 暫停與清除

在 **排程** 按 **暫停**，檢查後套用，之後就不會再備份；按 **繼續** 恢復。已有的備份和存放位置都會保留，備份照各自的 **保留到** 日期到期。

Zeabur 沒有刪除備份或排程的操作。測試完可以先暫停，讓測試備份自然到期；要馬上刪掉，用 `velero backup delete` 或 `velero schedule delete`。移除 [S3 目的地](./s3-destinations.mdx) 只會刪掉目的地本身，已經複製到 Velero 的金鑰、排程和 S3 裡的備份都會留著。
