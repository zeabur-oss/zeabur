打開 **叢集** → **元件**，先看 **已安裝** 有什麼，再到 **目錄** 找需要的元件。按卡片上的 **安裝**，選好 **安裝方式**、看過相依項目和權限，再選一種格式安裝。

![叢集元件頁的已安裝清單和目錄](https://oss.zeabur.com/shots/zeabur/zh-TW/light/cluster-components.avif)

## 開始之前

- 你能讀取整個叢集的 CRD、IngressClass 和各 Namespace 的工作負載，元件頁才偵測得到已安裝的元件。
- 要由 Zeabur 安裝，叢集要有對應的控制器：K3s/RKE2 內建的 Helm 控制器、Flux 或 Argo CD。你也要能在它的 Namespace（`kube-system`、`flux-system` 或 `argocd`）建立物件，管理員帳號就有這個權限。
- 如果這個元件已經由 Helm、Flux 或 Argo CD 管理，先找到原本的設定，在那裡修改。

## 先確認叢集裡已有什麼

**已安裝** 列出偵測到的元件、版本和安裝來源（K3s、HelmChart 或 Helm），並標出版本是 Zeabur Catalog 的 **已測試版本**，還是 **比已測試版本新**。

**目錄** 可以用 **已安裝** 或 **推薦** 篩選，也可以用 **搜尋元件** 找名稱或用途。

如果備份、通知這類功能頁已經能用，元件卡片卻還顯示 **安裝**，代表元件頁沒偵測到它，多半是用其他名稱或方式安裝的。先找到現有的部署，不要再裝一份。

## 安裝需要的元件

<Steps>
<Step>

### 開啟安裝內容

在元件卡片按 **安裝**，在 **安裝方式** 選 **單一節點** 或 **多個節點**。預設會依叢集的節點數選好，標示 **適合這個叢集**。

接著看 **需要先安裝**、**權限**、**會連到**、**認證資訊**、**風險** 和 **需要填入的值**。元件用不到的項目不會顯示。

</Step>
<Step>

### 選擇格式並安裝

分頁只列出叢集用得上的格式：**Helm** 一定會有，**K3s/RKE2 HelmChart**、**Flux**、**Argo CD** 要叢集裡有對應的控制器才會出現。

<Tabs items={["K3s/RKE2 HelmChart、Flux、Argo CD", "Helm"]}>
<Tab value="K3s/RKE2 HelmChart、Flux、Argo CD">

按 **檢查並安裝**。檢查要在 `kube-system`、`flux-system` 或 `argocd` 建立的每個物件，確認後套用。

控制器通常會在幾分鐘內依這些物件裝好 chart。記下物件名稱，之後要調整或移除都在這些物件上做。

</Tab>
<Tab value="Helm">

複製指令，到能用 `helm` 和 `kubectl` 連到叢集的電腦上執行。Zeabur 不會替你執行這些指令。

</Tab>
</Tabs>

以下情況沒有 **檢查並安裝**，分頁會寫出原因：元件需要你填值、包含一般 manifest、要先停用 K3s/RKE2 內建的同一個元件，或需要存取主機。這時填好 **需要填入的值**，用 `kubectl` 套用，或提交到 GitOps 儲存庫。需要存取主機的元件，內容會先把它的 Namespace 設為「不受限」（Pod Security 的 `privileged`）；叢集預設為嚴格時（例如套用 CIS 設定的 RKE2），少了這一步元件就無法啟動。

</Step>
<Step>

### 確認安裝結果

裝好後，**叢集** → **元件** 的 **已安裝** 會出現這個元件和版本。再回到需要它的功能頁確認，例如 Velero 對應 **叢集** → **備份**，VictoriaMetrics 對應 **叢集** → **通知**。

功能頁還是說缺少元件時，看 Helm 控制器或 GitOps 工具的安裝結果，以及元件的工作負載有沒有啟動。

</Step>
</Steps>

## 替換 K3s/RKE2 內建元件

安裝視窗要求先停用內建版本時，依叢集的發行版處理每台 server，再照安裝內容部署新的版本：

- K3s：在 `/etc/rancher/k3s/config.yaml` 把畫面列出的元件加進 `disable`，重新啟動 `k3s`。
- RKE2：metrics-server 是在 `/etc/rancher/rke2/config.yaml` 把 `rke2-metrics-server` 加進 `disable`；Traefik 是在同一個檔案設定 `ingress-controller: none`。之後重新啟動 `rke2-server`。

<Callout type="warn">
停用內建的 Traefik 會刪除 Traefik 的 CRD 和所有 IngressRoute、Middleware 物件，新的元件開始執行前，Ingress 流量會中斷。停用內建的 metrics-server 時，新版本開始執行前 metrics API 無法使用。挑可以中斷的時段切換。
</Callout>

## 常見失敗

- 元件頁顯示權限不足：把畫面列出的缺少權限交給叢集管理員。
- 沒有 **檢查並安裝**：看分頁寫的原因，複製內容自己套用。
- 只有 **Helm** 分頁：叢集裡沒有 Helm 控制器、Flux 或 Argo CD，複製 Helm 指令自己執行。
- 分頁說已經裝好了：找到當初安裝它的物件或工具，在那裡修改，不要再裝一份。
- 套用後一直沒出現在 **已安裝**：看 Helm 控制器的安裝 Job 和元件工作負載有沒有錯誤。

## 移除元件

元件頁沒有移除按鈕。用 K3s/RKE2 HelmChart 或 Flux 安裝的元件，刪除當時建立的 `HelmChart` 或 `HelmRelease`，控制器就會解除安裝。用 Argo CD 安裝的，在 Argo CD 刪除 `Application` 時選擇連同資源一起刪除。自己安裝的元件，從原本的 Helm、Flux 或 Argo CD 設定移除。

移除前，先停掉用到它的功能，例如備份排程、通知管道或經過它的公開流量。移除後回到 **已安裝** 和這些功能頁確認。
