用 Zeabur 查看 Kubernetes 裡的服務、日誌與網域。調整設定時，先**檢查變更**再套用。依手上的環境選一個起點。

## 從一台伺服器開始

在全新的 Linux 伺服器上，先用 Zeatend 裝好 Kubernetes，再用一個 `helm install` 裝上 Zeabur。

[在一台伺服器安裝 Zeabur](get-started/quickstart.mdx)

## 使用既有 Kubernetes 叢集

準備叢集管理權限和 Helm。Chart 會一起安裝 Zeabur Identity，kube-apiserver 要信任它，做法見[把 Zeabur 裝進既有叢集](install/existing-cluster.mdx)。Zeabur 的網址要能用 HTTPS 開啟，瀏覽器才會提供通行密鑰。

完成後，用通行密鑰登入 Zeabur，在**專案**找到既有的 Namespace，或新增專案部署服務。

[把 Zeabur 裝進既有叢集](install/existing-cluster.mdx)

## 下一步

已有可登入的 Zeabur 後，接著[部署第一個服務](get-started/first-project.mdx)。
