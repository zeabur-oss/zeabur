依你的情況選一頁開始。每一條路線都會帶你裝好 Zeabur 開源版，並用通行密鑰登入。

| 你的情況 | 從這一頁開始 |
| --- | --- |
| 想讓 Claude Code 或 Codex 代勞 | [交給 Agent 安裝或搬家](install/agent.mdx) |
| 有一台全新的 Linux 伺服器 | [用 Zeatend 安裝](install/one-command.mdx) |
| 已經在跑 Kubernetes 叢集 | [把 Zeabur 開源版裝進既有叢集](install/existing-cluster.mdx) |
| 正在用 Zeabur，想把服務搬過來 | [從 Zeabur 過來](get-started/from-zeabur-com.mdx) |

Kubernetes 是在一台或多台伺服器上執行容器的開源系統，叢集就是一組由它管理的伺服器。Zeatend 會在新伺服器上裝好 Kubernetes。每一條路線最後都用同一個 `helm install` 安裝 Zeabur 開源版，Helm 是 Kubernetes 的安裝工具。

只想在自己的電腦上看看叢集，不必安裝到叢集裡，見 [Zeabur Desktop](install/desktop.mdx)。
