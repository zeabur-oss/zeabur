用 Zeabur 查看 Kubernetes 裡的服務、日誌與網域。調整設定時，先**檢查變更**再套用。依手上的環境選一個起點。

## 從一台伺服器開始

準備一台使用 systemd 的 Linux 伺服器、root 權限，以及指向這台主機的登入與管理網域。Zeabur Installer 的網頁介面會一步步檢查伺服器、選元件，再安裝 RKE2、Zeabur Identity 和 Zeabur。

完成後，畫面會顯示 Zeabur 網址與第一位管理員的通行密鑰註冊連結。登入後就能建立第一個專案。

[在一台伺服器安裝 Zeabur](get-started/quickstart.mdx)

## 使用既有 Kubernetes 叢集

準備叢集管理權限、Helm，以及 kube-apiserver 已信任的 Zeabur Identity。Zeabur 的網址要能用 HTTPS 開啟，瀏覽器才會提供通行密鑰。

完成後，用通行密鑰登入 Zeabur，在**專案**找到既有的 Namespace，或新增專案部署服務。

[把 Zeabur 裝進既有叢集](get-started/install.mdx)
