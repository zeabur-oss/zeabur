---
title: Zeabur Desktop：在自己的電腦開啟叢集
description: 在 macOS、Windows 或 Linux 安裝 Zeabur Desktop，替 kubeconfig 裡的任何叢集開啟 Zeabur 開源版，並保持最新版本。
---

Zeabur Desktop 會列出你電腦上 kubeconfig 檔案裡的 context，你選哪一個，它就在新視窗替那個叢集開啟 Zeabur 開源版。它做的事和 `zeaburctl ui` 一樣，只是不用開終端機。

## 用 Homebrew 安裝

在裝了 [Homebrew](https://brew.sh) 的 Apple 晶片 Mac 上，不用自己下載，直接用它安裝：

```sh
brew tap zeabur-oss/tap
brew install --cask zeabur-oss/tap/zeabur-desktop
```

Homebrew 裝的是發行頁面上同一個已簽署的 `.dmg`，並用該版本的 checksum 核對檔案。

想試用最新的預先發行版本，就安裝 `zeabur-desktop@beta`。它和 `zeabur-desktop` 是同一個 App，所以要先解除安裝 `zeabur-desktop`：

```sh
brew install --cask zeabur-oss/tap/zeabur-desktop@beta
```

## 下載

到 [GitHub Releases](https://github.com/zeabur-oss/zeabur/releases) 選一個版本，下載符合你電腦的檔案：

| 電腦 | 檔案 |
|---|---|
| Apple 晶片的 Mac | `zeabur-desktop-v<version>-darwin-arm64.dmg` |
| x64 的 Windows | `zeabur-desktop-v<version>-windows-amd64-setup.exe`；不想安裝就用 `-portable.exe` |
| Debian 或 Ubuntu | `zeabur-desktop-v<version>-linux-<arch>.deb` |
| Fedora、RHEL 或 openSUSE | `zeabur-desktop-v<version>-linux-<arch>.rpm` |
| 其他 Linux | `zeabur-desktop-v<version>-linux-<arch>.AppImage` |

Linux 的 `<arch>` 是 `amd64` 或 `arm64`。沒有 Intel Mac 和 Arm 版 Windows 的版本。每個版本的 `SHA256SUMS` 也涵蓋這些檔案，驗證方式請看[發行檔與驗證](../reference/releases.mdx)。

## 安裝

- **macOS**：開啟 `.dmg`，把 Zeabur 開源版拖進「應用程式」。
- **Windows**：執行 `-setup.exe`。它只替你的帳號安裝，不需要系統管理員權限。
- **Debian 或 Ubuntu**：`sudo apt install ./zeabur-desktop-v<version>-linux-<arch>.deb`
- **Fedora、RHEL 或 openSUSE**：`sudo dnf install ./zeabur-desktop-v<version>-linux-<arch>.rpm`，openSUSE 用 `zypper install`。
- **AppImage**：用 `chmod +x` 讓檔案可以執行，再執行它。

## 更新

Zeabur Desktop 每次啟動都會檢查有沒有新版本。有的話，側邊欄會出現「更新到 0.3.1」這樣的按鈕。想自己檢查時，按側邊欄底部版本號旁的「檢查更新」；在 macOS 也可以選「Zeabur 開源版 > 檢查更新…」。

更新會先列出更新內容，你按下「更新並重新啟動」才會安裝。接著 Zeabur 開源版會關閉視窗，以新版本重新啟動。正式版本只會收到較新的正式版本。預先發行版本（例如 `0.3.0-beta.1`）也會收到較新的預先發行版本，之後再收到對應的正式版本。

macOS 的 App、用 Windows 安裝程式裝的 Zeabur 開源版和 AppImage 都能自行更新，用 Homebrew 裝的 App 也一樣；`brew upgrade --greedy` 也能更新它。`.deb`、`.rpm` 和免安裝的 `.exe` 不行：Zeabur 開源版會告訴你有新版本，請到發行頁面下載，用第一次安裝的方式再裝一次。
