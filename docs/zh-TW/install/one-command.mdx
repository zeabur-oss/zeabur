---
title: 用 Zeatend 安裝
description: 在一台全新的 Linux 伺服器上，先用 Zeatend 裝好 Kubernetes，再用一個 helm install 裝上 Zeabur 開源版。
---

照這一頁做完，新的 Linux 伺服器上會跑著 Kubernetes 和 Zeabur 開源版，你可以用 HTTPS 打開 Zeabur 開源版，用通行密鑰登入。

已經有叢集？見[把 Zeabur 開源版裝進既有叢集](existing-cluster.mdx)。想讓 Claude Code 或 Codex 代你做，見[交給 Agent 安裝或搬家](agent.mdx)。

## 開始之前

- **一台 Linux 伺服器**，有公開 IP 位址，80 和 443 埠能從網際網路連進來。Let's Encrypt 會透過 80 埠檢查網址。記憶體和磁碟要多大，見 Zeatend 的[支援的伺服器與檔案](https://oss.zeabur.com/zh-TW/docs/zeatend/reference/hosts/)。
- **伺服器的 root 權限**，透過 SSH 登入。下面的指令都以 root 執行，用一般帳號登入時先執行 `sudo -i`。
- **伺服器上的 Zeatend、Helm 4 和 `zeabur-identityctl`**。Zeatend 的下載方式見[下載 Zeatend](https://oss.zeabur.com/zh-TW/docs/zeatend/get-started/install/#下載-zeatend)；`zeabur-identityctl` 見 Zeabur Identity 的[發行檔與驗證](https://oss.zeabur.com/zh-TW/docs/identity/reference/releases/)。

<Steps>
<Step>

### 選好網域

照[選好網域](existing-cluster.mdx#選好網域)在伺服器上設定 `DOMAIN`。用自己的網域時，DNS 紀錄指向這台伺服器。

</Step>
<Step>

### 用 Zeatend 裝好 Kubernetes

```sh
zeatend plan
```

`zeatend plan` 會檢查伺服器、列出要安裝的內容，不會改動任何東西。出現 `FAIL` 時，先照那一行的說明處理，見 Zeatend 的[檢查安裝計畫](https://oss.zeabur.com/zh-TW/docs/zeatend/get-started/install/#檢查安裝計畫)。沒有 `FAIL` 就安裝：

```sh
zeatend apply
```

`zeatend apply` 會安裝 K3s，並顯示每個步驟。SSH 斷線時安裝會繼續，再執行一次 `zeatend apply` 就能接著看。

</Step>
<Step>

### 讓叢集信任登入

下一步裝好的 Zeabur Identity 會發出登入權杖，Kubernetes 要在 Zeatend 的 `apiServer.authenticationConfig` 把它設為可信任的簽發者，才會接受。`zeabur-identityctl kube-config` 印出這段設定，它要讀叢集，所以等叢集裝好才執行。第二次 `zeatend apply` 會帶著這段設定重新啟動 K3s：

```sh
export KUBECONFIG=/etc/rancher/k3s/k3s.yaml
mkdir -p /etc/zeatend
authn=$(mktemp)
zeabur-identityctl kube-config --issuer "https://identity.$DOMAIN" --distro k3s --discovery public > "$authn" && {
  printf 'distribution: k3s\napiServer:\n  authenticationConfig:\n'
  sed 's/^/    /' "$authn"
} > /etc/zeatend/config.yaml &&
  zeatend apply
```

`zeabur-identityctl` 也會印出手動安裝這段設定的做法，不用理它，Zeatend 會代你做。如果它印出的是錯誤，就不會寫入 Zeatend 的設定檔，`zeatend apply` 也不會執行。照錯誤訊息處理後，再執行一次這段指令。

</Step>
<Step>

### 安裝 Zeabur 開源版

Helm 使用上一步設好的 K3s kubeconfig。開了新的 SSH 連線時，先執行 `export KUBECONFIG=/etc/rancher/k3s/k3s.yaml`。照[用 Helm 安裝](existing-cluster.mdx#用-helm-安裝)執行 `helm install`，再照[建立管理員帳號](existing-cluster.mdx#建立管理員帳號)用通行密鑰登入。上一步已經讓叢集信任登入，不用再做那裡的「讓叢集信任登入」。

</Step>
</Steps>

登入後，其他需要的元件到**叢集** → **元件**頁面安裝，見[檢視與安裝叢集元件](../cluster/components.mdx)。
