Claude Code 或 Codex 這類 Coding Agent 可以替你照著安裝步驟做。它讀的頁面和你一樣，會自己執行指令，遇到要你決定或付錢的地方就停下來。

## 貼上這段提示

```text
照著 https://oss.zeabur.com/zh-TW/docs/zeabur/install/one-command.md 把 Zeabur 開源版裝到我的伺服器上。
如果伺服器已經在跑 Kubernetes，改照 https://oss.zeabur.com/zh-TW/docs/zeabur/install/existing-cluster.md 安裝。
每次改動伺服器之前，先告訴我要做什麼，等我同意。建立管理員帳號的連結交給我，不要自己打開。
```

這兩個網址分別指向[用 Zeatend 安裝](one-command.mdx)和[把 Zeabur 開源版裝進既有叢集](existing-cluster.mdx)的 Markdown 版。在能用 SSH 連到伺服器的電腦上執行 Agent，並告訴它伺服器的位址。

## Agent 會做的事

1. 檢查伺服器，改動任何東西前先問你。
2. 伺服器還沒有 Kubernetes 時，用 Zeatend 裝好。
3. 用一個 `helm install` 安裝 Zeabur 開源版。
4. 給你 Zeabur 開源版的網址，以及建立管理員帳號的連結。

## 你自己要做的事

- 準備伺服器並付費。
- 想用自己的網域而不是 sslip.io 網址時，把網域的 DNS 紀錄指向伺服器。
- 打開連結，建立通行密鑰，再用通行密鑰登入 Zeabur 開源版。通行密鑰只能由你在自己的裝置上建立。

## 從 Zeabur 搬過來

要把 Zeabur 上的服務一起搬過來，改用[從 Zeabur 過來](../get-started/from-zeabur-com.mdx#交給-coding-agent-搬家)的提示。Agent 會準備伺服器、裝好 Zeabur 開源版，再搬移服務和資料。
