## 完成後你會有

- 一台你自己的伺服器，上面跑著 Zeabur。
- 一個 Zeabur 的網址，以及第一次登入的方式。
- 如果你要搬家，zeabur.com 上的服務和資料也會在新伺服器上執行。

## 之後的流程

1. 你把一段提示貼進 Claude Code 或 Codex。提示只有一句話，裡面附上這一頁的網址。
2. Agent 讀這一頁，問你要用哪一家的伺服器、哪個方案，並列出價格。你確認之後，它才會購買。
3. Agent 用 Zeatend 在新伺服器上裝好 Kubernetes 和 Zeabur。
4. 要搬家時，Agent 依照 zeabur.com 的[搬家指南](https://zeabur.com/zh-TW/blogs/migrate-from-zeabur)列出你的服務、備份資料庫，再在 Zeabur 上重建服務、還原資料。
5. 最後，Agent 會告訴你 Zeabur 的網址，以及第一次怎麼登入。

提示大概會長這樣。現在還請不要使用，這一頁還沒有寫好給 Agent 看的步驟：

> 讀 〈這一頁的網址〉，在我自己的伺服器上安裝 Zeabur，並把 zeabur.com 上的〈專案名稱〉搬過去。

## 你自己要做的事

Agent 會在這幾步停下來，等你處理：

- 確認要買的伺服器和價格。
- 付款。
- 修改網域的 DNS，把網址指到新伺服器。
