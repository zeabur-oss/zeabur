# `zeaburctl` for Windows and Intel Macs

Releases have `zeaburctl` for Windows (`zeaburctl-v<version>-windows-amd64.zip`, with `zeaburctl.exe`) and for Intel Macs (`zeaburctl-v<version>-darwin-amd64.tar.gz`), beside the Linux and Apple silicon builds. The Homebrew formula installs on Intel Macs too.
