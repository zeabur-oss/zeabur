# MongoDB Controllers for Kubernetes databases show in the project

A `MongoDBCommunity` made with MongoDB Controllers for Kubernetes now shows in the database list, on the project map and on its own page, with its state, members and how to connect. Zeabur OSS only shows these databases: it does not change, back up or restore them, and the page says why. Members can read them; a member who cannot sees a note instead of a missing database.
