The Job {{ printf "%s-components" (include "zeabur.fullname" .) | trunc 63 | trimSuffix "-" }} installs {{ join ", " .Values.components.install }} from Zeabur Catalog
and retries for about 45 minutes. Follow it with:

  kubectl -n {{ .Release.Namespace }} logs -f job/{{ printf "%s-components" (include "zeabur.fullname" .) | trunc 63 | trimSuffix "-" }} --all-containers
{{- end }}
{{- if and .Values.identity.enabled .Release.IsInstall .Values.identity.admin.setupLink }}

Create the first administrator ({{ .Values.identity.admin.user }}) in a browser. The link works
once and expires in {{ .Values.identity.admin.validFor }}:

  {{ $issuer }}/setup#token={{ include "identity.setupToken" (dict "Values" .Values.identity) }}

The certificates can take a minute after install. If the link has expired, issue another with:

  zeabur-identityctl setup-link --issuer {{ $issuer }} --username {{ .Values.identity.admin.user }}
{{- else }}

Sign in through {{ $issuer }}.
{{- end }}

kube-apiserver must accept the sign-in tokens of {{ $issuer }}.
`zeabur-identityctl kube-config --issuer {{ $issuer }}` prints its configuration.

{{- if .Values.memberRoles.enabled }}

Zeabur gives members their rights with RoleBindings and ClusterRoleBindings it makes itself.
`helm uninstall` leaves them. After it, remove them with:

  kubectl delete rolebindings,clusterrolebindings --all-namespaces \
    -l app.kubernetes.io/managed-by=zeabur,zeabur.com/member
{{- end }}

{{- if not .Values.telemetry.enabled }}

Help us improve Zeabur: join the experience program

Out of the box, Zeabur sends nothing, so we can't tell whether anyone runs it
or which fixes matter most. Joining sends one event a day for each person who
uses this install, with the version and a random ID. It never says who they
are: no names, domains or emails, and PostHog doesn't keep IP addresses.

Join with one command:

  helm upgrade {{ .Release.Name }} oci://ghcr.io/zeabur-oss/charts/zeabur --namespace {{ .Release.Namespace }} --version {{ .Chart.Version }} --reset-then-reuse-values \
    --set telemetry.enabled=true \
    --set telemetry.installationId=$(uuidgen | tr 'A-Z' 'a-z')

What is sent: https://oss.zeabur.com/docs/zeabur/reference/telemetry/
{{- end }}
