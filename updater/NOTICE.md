# Third-party software

The database updater links the unmodified Keel 0.22.4 source at
https://github.com/keel-hq/keel/tree/bc640168f020ab1dc89842938d1883886242a40b
(Mozilla Public License 2.0). Its source is available from that URL and through
the exact module version recorded in go.mod and go.sum. No Keel source files
are modified or copied into Zeabur.

The image includes the linked Go modules' license and notice files under
/licenses. The Go toolchain's license is included there too. Zeabur's adapter
source is covered by this repository's Apache License 2.0.
